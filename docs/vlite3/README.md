# vlite3 documentation

This directory is synchronized automatically from the installed `vlite3` npm package.

Files managed by vlite3 may be added, updated, or removed when you install or upgrade the package. Project-specific notes should live outside `docs/vlite3/` so they are not replaced.

If dependency lifecycle scripts are disabled in your environment, sync manually:

```bash
npx vlite3-docs
```
